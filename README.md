# 🌸 My Awesome Portfolio

Website portofolio pribadi yang menampilkan profil, keterampilan, dan proyek yang telah saya buat sebagai siswi **PPLG/RPL SMKN 5 Malang**.

---

## 👩‍💻 Tentang Proyek

Website ini dibuat sebagai media untuk memperkenalkan diri, menampilkan kemampuan di bidang pengembangan web, serta mendokumentasikan beberapa proyek yang pernah saya kerjakan.

---

## ✨ Fitur

- 🏠 Halaman Home
- 👩 Tentang Saya (About)
- 💼 Daftar Proyek (Projects)
- 📞 Halaman Kontak (Contact)
- 📱 Responsive Design
- 🎨 Tampilan modern menggunakan Bootstrap 5
- ✨ Animasi dan efek interaktif

---

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

---

## 📂 Struktur Folder

```text
portfolio-rina/
│── img/
│── index.html
│── style.css
│── style.js
└── README.md
```

## 🚀 Cara Menjalankan

1. Download atau clone repository ini.

```bash
git clone https://github.com/imrinnaa/imrinnaa.github.io.git
```

2. Masuk ke folder project.

```bash
cd imrinnaa.github.io
```

3. Buka file `index.html` menggunakan browser.

---

Website terdiri dari beberapa bagian, yaitu:

- About
- Projects
- Contact
